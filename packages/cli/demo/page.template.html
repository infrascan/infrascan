infrascan quickstart, recorded

One run of quickstart with no flags. It builds an environment of two accounts, each with its own regions, saves it for reuse, then scans both into one graph.

The AWS account in this recording is simulated. The CLI is the real build from the branch, but it was pointed at a local stand-in for the AWS APIs that serves a small example app in every account and region (three Lambda functions, an SQS queue, an SNS topic, a DynamoDB table and an S3 bucket). Profiles, account IDs and timings are illustrative.
